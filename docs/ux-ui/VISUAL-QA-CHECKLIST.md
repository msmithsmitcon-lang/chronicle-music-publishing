## Hierarchy

- [ ] The primary action or content area is visually clear.
- [ ] Headings, labels, and supporting copy have appropriate scale.
- [ ] Important information is not buried in low-contrast or low-priority styling.
- [ ] Repeated elements have a predictable visual order.

## Spacing

- [ ] Page sections have consistent spacing.
- [ ] Cards, panels, and controls have balanced internal padding.
- [ ] Related items are grouped clearly.
- [ ] Unrelated items have enough separation.
- [ ] Mobile spacing remains usable without feeling cramped.

## Responsiveness

- [ ] The surface works at mobile, tablet, and desktop widths.
- [ ] Text does not overflow or collide with controls.
- [ ] Navigation and toolbars remain usable on small screens.
- [ ] Fixed-format elements keep stable dimensions.
- [ ] Horizontal scrolling is intentional where present.

## Alignment

- [ ] Layout edges align consistently.
- [ ] Controls align with labels and content.
- [ ] Cards and panels follow a coherent grid.
- [ ] Icons and text are vertically centered where appropriate.
- [ ] Empty states and loading states align with the surrounding layout.

## Image Quality

- [ ] Images are relevant to the actual product, person, place, object, or workflow.
- [ ] Images are not blurry, distorted, or awkwardly cropped.
- [ ] Aspect ratios are stable across breakpoints.
- [ ] Overlays preserve readability.
- [ ] Fallback states are defined where needed.

## Backend Preservation

- [ ] No backend code was modified.
- [ ] No Supabase schemas, policies, queries, migrations, or client logic were modified.
- [ ] No runtime orchestration was modified.
- [ ] No workflow, API, authentication, authorization, billing, finance, or entitlement logic was modified.
- [ ] No asset-system logic was modified.

## Operational Clarity

- [ ] The surface makes the user's next action clear.
- [ ] Status, ownership, progress, or operational state is visible where relevant.
- [ ] Labels use domain language consistently.
- [ ] Empty, loading, success, warning, and error states are understandable.
- [ ] Dense operational views remain scannable.

## Accessibility Awareness

- [ ] Text contrast appears sufficient.
- [ ] Interactive controls have visible focus states.
- [ ] Icon-only actions have accessible names or tooltips.
- [ ] Form fields have labels or equivalent accessible context.
- [ ] Motion, animation, and transitions do not obscure usability.

## Consistency Checks

- [ ] The surface follows the project design system.
- [ ] Buttons, cards, shadows, radius, spacing, and typography are consistent.
- [ ] New UI does not conflict with locked sections.
- [ ] Visual reference guidance was applied only where appropriate.
- [ ] The final result matches the approved scope.
